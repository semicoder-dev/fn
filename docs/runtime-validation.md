# 全插件化候选验收（2026-10-22）

基于 fn 0.5.2/main `4c90020`，分支 `codex/all-plugins`，用户已授权本地提交，未升版/发布。上游仍为 dsh 0.2.1-rc.2、Cordis 4.0.5、Pi 1.1.0、Bun 1.4.3；40 个固定归档及闭包校验通过。既往发行验证保存在 `v0.5.2` 等历史标签和 [发行记录](github-release.md)，不能代替本轮验证。

## 自动化与独立消费

- fn TypeScript / FIA 应用检查通过；`bun test ./tests ./packages/host/tests ./packages/sdk/tests ./plugins`：110 项、808 断言。
- 原 Loader/Include 装配、原客户端模块 factory/Slots/renderer、SQLite 单写者/序号/flush/fork、写入失败阻断工具、取消与恢复、同 provider 连接隔离及凭证转换、Chat 去重/离线/已添加模型筛选均由实际内核合同覆盖。
- 嵌套两个插件使用相同局部卡片 action/key 时相互隔离；销毁其中一个会取消其在途 handler，另一个仍可响应。卡片在调用前认领持久状态，失败/重启不自动重放。
- `bun run npm:pack`：实际 SDK 归档在 workspace 外安装、构建并打包双端夹具，原版 Slots 和 CSS effect 撤销通过。FIA `framework:check`：90 JS/48 Swift，通过；`framework:verify`：独立框架归档及独立应用消费通过。
- `bun run build` 打包启动通过；`scripts/upstream/generation-smoke.ts` 验证实际 TypeScript + 私有 zod 安装、共享 Cordis、禁止安装脚本、冻结锁及离线重启。
- Apple FnChatCore 7 项、FnChatUI 4 项通过；FnPhone iOS Simulator 编译成功，包内 Chat v4 契约资源校验通过。原 `ios/` 探针删除，签名辅助工程集中在 `clients/apple/`。
- fn-plugins 空 schema 3 索引检查、Semicoder 34 篇内容生成/校验与文档链接检查通过。公开安装默认路径与版本未切换。

## 实际应用与浏览器

使用隔离 FIA 数据/控制目录、固定应用副本，测试夹具来自 `tests/fixtures/plugins/`，不读取日常账号或用户数据。

- 从空目录启动默认 profile，模型、Chat、紧凑侧栏、设置、外观、更新和市场界面均来自插件。
- 纯后端、纯前端、双端 npm 归档真实安装成功；共享资源和 CSS 正常加载。长任务期间候选保持待应用，任务结束才重启，FIA 窗口保留。
- 注入后端初始化错误会自动回退；配置可整体替换布局；布局渲染错误显示宿主恢复页。新代仅在后端和根 UI 均成功后确认；失败 UI 可恢复紧邻的有效组合或默认组合。
- 卡片表单提交、一次性认领、Session 投影和本地 Pi/SSE 回复通过。文件工具在 UI 批准后才写入隔离目录。
- 两个同 provider 模型连接、预设列表、已添加模型筛选、会话创建、明暗主题与应用更新状态核对通过。生产市场仍是旧协议，候选明确提示不兼容，不自动迁移。

浏览器回归暴露并修复：缺失 renderer 必需的 Session scope 适配器、客户端模块 ID 正规化、插槽声明顺序、资源 URL 和宽度样式、失败根插槽恢复。重启后需新 FIA 浏览器票据；复用同一个引导 URL 只改 hash 不会重新执行脚本，验收脚本使用完整导航。模型基准等待具体 Session idle，不把市场网络刷新误判为模型未完成。

## 截图反馈后的样式复验

同日用户反馈侧栏出现普通按钮边框、外观页右侧大片留白。已复现：未分层的通用按钮选择器覆盖导航样式；原版 Slot 的 `display: contents` 包装层不形成 Flex 布局项，内容按自身宽度收缩。修复位于 `fn-ui-base/layout/settings/theme`：默认原生控件样式进入 base 层，布局使用单列 Grid 拉伸实际贡献，设置页宽度填充并独立滚动，移除重复的主题选择框描边。

修复后应用检查、样式检查、构建和真实浏览器复验通过；1110/1200 px 宽窗口、700 px 窄窗口、明暗主题、模型/更新/Chat/应用中心宽度及设置页底部滚动核对。Dev 已自动装载同一 seed。首轮手动构建与正在运行的 Dev 自动构建相撞（seed rename ENOTEMPTY），待 Dev 完成后串行构建通过，没有改动运行目录内容来绕过构建。

官网候选页面已描述紧凑侧栏、可替换布局和主题；本轮恢复这些既定行为，没有新增 API 或安装边界，官网内容无需修改。下方性能测量属于此前全插件化构建，本轮四份插件 CSS 修复未重新测量性能。

## 性能

关闭交互验收后，同机串行测量旧版和最终构建，各 3 次全新目录 + 3 次已存数据重启，中位数如下；完整原始样本、seed/代码摘要和方法见 [测量 JSON](plugins-benchmark-2026-10-22.json)。

| 指标                     | 0.5.2 公开应用 |    新候选 |
| ------------------------ | -------------: | --------: |
| 空目录 UI 就绪（含解包） |         5.87 s |    5.98 s |
| 已有数据 UI 就绪         |        0.810 s |   0.911 s |
| 首次本地模拟回复持久化   |        51.0 ms |   48.3 ms |
| 首次就绪 Host+Bun RSS    |      253.0 MiB | 264.4 MiB |
| 重启就绪 Host+Bun RSS    |      205.2 MiB | 212.0 MiB |

初测发现重复携带 FIA 原生资产导致 seed 约 65 MiB；移除 `assets/` 重复副本后最终归档约 35 MiB。原生 Host/Bun 仍由应用外层 runtime 提供。新增上游客户端包、UI 模块及解析增加少量启动/内存开销；保留数据重启后端均约 0.71 s；候选额外等待两帧根 UI 渲染再确认激活。交互验收并行时曾测得约 8 s 首次启动，原始波动样本也保留，未混入最终串行对照。没有清 OS 缓存，100 ms 就绪采样存在量化误差，RSS 不含 WebKit/系统进程。

三个无私有依赖的测试插件离线准备约 0.13 s/包；纯后端/双端真实安装至后台重启曾测得约 1.0/1.4 s。排除网络下载、初始物化和忙时等待，夹具不等于旧官方三包，不能宣称旧/新同样本加速比例。安装不会重新复制核心。

## 未验证和发行边界

真实 OAuth 登录/过期刷新/第二账号、手机真机卡片/跨设备模型/通知定位、Chat v4 生产 CloudKit schema/订阅均未验证或部署；内存传输、模拟 HTTP 和编译不替代这些证据。未执行签名公证、TestFlight 上传、npm/应用发行或官网部署。

新数据根 `plugins-v1` 与 Chat v4 独立于旧空间；没有读取、迁移、删除旧用户数据。远端市场和历史附件保持原状。完整默认功能由配置提供；默认包仍携带 JS/类型依赖，运行期不安装依赖、执行 npm 生命周期或移植 Node HMR。
