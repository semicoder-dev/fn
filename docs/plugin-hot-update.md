# 插件热更新（fn 0.6.1）

基线 fn `9a132b1` / 0.6.0，发布目标为 0.6.1/build 14。保留 Bun 1.4.3 和现有 FIA，不引入 Node 运行时、Node 内部缓存 API 或旁路服务。用户确认保持 SDK 0.5.0 原始公开内容，避免现有插件的精确 peer 阻止升级；SDK 新字段工具支持暂缓。

## 激活与恢复

安装继续验证归档、精确共享依赖、独立私有依赖闭包和预导入，创建不可变候选。`GenerationManager` 写入待激活指针，空闲时关闭新任务准入，再按变更范围选择增量激活或重启。

普通外部叶子插件通过新的真实版本目录导入。Loader 先释放受影响模块的 Cordis runtime/fiber，再创建新入口；服务依赖由 Cordis 重新绑定。未变化的入口不执行 root.update，保留实例和状态。已卸载模块不假设能从 Bun 缓存移除。

客户端通过现有 FIA 事件获取新组合，使用原版客户端模块引擎和 Loader；沿用未变化的已物化模块、renderer 和根 Context，只更换变化入口。延迟脚本注册回请求它的模块引擎，历史资源 URL 在进程内继续可读，避免未变化页面的图片/字体失效。变化插件的组件草稿不承诺保留，持久数据由插件管理。

最近活跃页面按 clientId + generationId 确认；3 秒轮询补偿事件遗漏。后端确认和页面确认完成后提交 ready 指针。释放/启动超过 15 秒、页面失败或 20 秒未确认时恢复旧指针并重启干净进程；不把释放部分资源后的状态宣称为已成功回滚。页面关闭或长时间挂起可能触发保守恢复。

## 重启边界

- seed、共享核心或基础插件组合改变。
- 外部插件拥有嵌套组合，或缺少独立不可变版本存储。
- 新旧任一版本声明 `fn.hotReload: false`。
- 同一进程完成 32 次热切换后，下一次切换通过重启回收旧模块与资源索引。
- 增量释放、启动或客户端确认失败：重启上一有效组合，保留错误。

插件默认遵守 Cordis 可释放注册契约；模块顶层副作用无法由宿主可靠推断，不能安全释放进程资源时必须显式退出热更新。宿主 0.6.1 支持 `hotReload` 保守重启声明，但保留的公开 SDK 0.5.0 构建器不接受此字段，本轮不将其列为公开 SDK 功能或用于正式市场。插件仍须遵守可释放契约；SDK 字段支持后续独立处理。

普通热更新不调用 FIA 后台重启，因此不触发其 WebView 重载，也不使浏览器授权过期。安全回退仍使用现有 FIA 受控重启：原生窗口重新连接，浏览器授权结束，需从应用重新打开。FIA 通用能力已满足本次需要，无框架源码修改。
