# Fn 0.8.0

- 首页统一为每个已安装应用一行，支持搜索、拖动及键盘排序，点击或 Enter 打开应用。
- 应用行支持动态文字、指标、徽标、进度与趋势；窄窗口自动调整布局，关闭后保留最后摘要和更新时间。
- 新 hostApi 2 与 ApplicationSummary，后台使用 application.setSummary 和独立 notifyDataChanged。移除旧小组件接口、布局和预览命令，CLI 改为 fn plugin summary。
- 摘要按实例独立缓存、串行原子写入和运行代校验；非法内容或写入失败保留有效内容。看板多视图同步与重连读取不再依赖摘要。
- GitHub 发布复用完整质量检查，公开 npm 归档自动核对和独立消费，官方应用增加仓库外冻结消费与公开依赖检查。

## 安装与应用更新

使用完整 DMG 更新 Fn，然后在应用中心更新应用。旧 hostApi 1 包保留管理入口但不能启动；官方翻译、笔记、看板、模型目录 0.3.0 使用新契约，业务数据目录保持。更新应用重置派生摘要，使用新包初始内容；无需删除业务数据。

SDK 0.7.0、UI 0.2.0；不保留旧 widgets API。手机正式版本仍未包含在本次发行中。

安装入口：https://semicoder.dev/fn/docs/installation
