# 待发布改动

## 插件增量安装与阶段提示

来源：`codex/faster-plugin-install`，基线 `8ca60f7` 加工作树。2026-10-22 用户授权发布，已归集到 [0.5.2 说明](0.5.2.md)并准备 build 12；正式发行尚待验收。用户确认参考 dsh 的内核/插件分离，取代此前仅加快整代复制的候选。

- 固定核心按 seed 共享，新插件及其私有依赖独立安装；generation 只记录选择和相对引用。安装、更新和卸载不再复制全部内核或未改动插件。
- 安装器使用共享 peer 的元数据占位，安装与冻结锁检查结束后连接固定核心，保留依赖单例审核和启动预检。
- 旧目录保持可启动/回退，候选仍等待空闲后重启。共享 seed 不覆盖，整个数据目录搬移后引用可恢复；历史目录暂不自动回收。
- 提示区分市场、归档、准备目录、依赖和启动检查。可复测命令与验证见 [runtime 记录](../../docs/runtime-validation.md)。
- 官网仅本地同步未发布边界。新源码进入固定 seed，后续发行需完整 DMG；SDK API、插件和手机版本不变。


SDK 0.4.0、三个 Cordis 官方应用 0.1.0、手机 0.3.0（4）和 agent-webtool 0.8.2 保持现有版本。后续开发继续在此归集，不预先升版。手机真机卡片/跨设备模型/通知、新 OAuth 登录/过期刷新/第二账号仍为待验收事项，见[能力矩阵](../../docs/core-capability-audit.md)。
