# fn 0.5.1

修复应用中心将随手记、译文和网络搜索误判为“核心版本不兼容”，三个官方 Cordis 0.1.0 应用恢复正常安装。

运行目录现在完整登记并校验宿主共享的 React 和 React DOM，安装时仍严格校验核心依赖与唯一实例。SDK 0.4.0、官方插件和 iPhone 0.3.0（4）保持现有版本，无需重新发布或重建插件。

## 升级

本次运行时资源发生变化，请从[官网安装页](https://semicoder.dev/fn/docs/installation)下载完整 DMG，退出 fn 后替换应用。0.5.0 的连接、会话、KV 和已安装应用保留；已有运行目录会在任务空闲后切换。无需清理数据或重新配置账号。

从 0.4.x 或更早版本升级仍适用 0.5 的独立数据目录规则：旧 SDK、插件和 Chat v2 不兼容，须重新配置新版连接与应用；旧数据不会被读取、迁移或删除。
