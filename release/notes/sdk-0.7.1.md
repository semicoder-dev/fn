# Fn SDK 0.7.1 / UI 0.2.1

本次独立发布开发包，Fn 桌面保持 0.8.0/build 16，hostApi 2 和 SDK API 不变。

- UI：Input / Textarea 聚焦复用原边框；Button / Select 键盘聚焦复用原边框，菜单项与无边框弹窗关闭按钮显示内部细线，避免重复外圈。
- SDK 0.7.1 与 UI 0.2.1 精确配套，包说明及源码 init 模板同步版本。
- 官方应用仅在 main 更新精确公开依赖和锁文件，应用版本、已公开归档及市场不变。
- 公开 Fn 0.8.0 内置的 init 模板仍使用旧开发包；创建项目后显式安装 SDK 0.7.1 / UI 0.2.1，再检查、构建和打包。
- 宿主应用行的单层焦点边框及新版内置模板等待后续 Fn 桌面发行，不包含在本次 npm 发布的生效范围内。

发行前已通过 Fn check、25 测试/185 断言、SDK/UI 归档独立消费；共享样式沿用已完成的明暗/窄窗/键盘/原生验收。正式标签为 sdk-v0.7.1，公开归档字节、OIDC 与独立消费结果见 docs/npm-release.md。
