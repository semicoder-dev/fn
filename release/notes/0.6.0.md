# fn 0.6.0

fn 进入全插件化阶段：应用界面、设置和业务能力均由独立 Cordis 插件组合提供，宿主专注启动、原生能力与运行恢复。

- 启动进入应用中心，可安装、管理独立插件，配置在任务空闲后生效。
- 默认界面统一原版 dsh 控件与浅色、深色、跟随系统主题；移除旧自定义配色。
- 官方市场提供看板 0.1.0：多个看板、列表与卡片拖动、共享标签、截止日期、检查清单、搜索、归档与恢复，数据保存在本机。
- 官方市场提供模型目录 0.1.0：浏览 models.dev 模型规格、能力与供应商价格，支持搜索、筛选、排序和缓存。
- SDK 0.5.0 提供普通 Cordis 插件契约、独立构建和类型化客户端；UI 与具体服务由所属插件提供。
- 聊天用途仍在设计，Chat 页面、默认助手、卡片与 iCloud 聊天同步不随本版发行。源码保留为可选开发实验组合。通用 Agent、Session、模型和工具能力继续供插件使用。

## 升级与兼容

必须下载完整 DMG 替换应用。本版不兼容 SDK 0.4 及更早插件，也不与现有手机 Chat 客户端同步。旧翻译、随手记和网页搜索插件不进入新市场。

从公开 fn 0.5.x 升级后，需重新配置模型连接和安装新版插件。新架构使用独立的 `plugins-v1` 数据目录，不读取、迁移或删除旧账号、应用、KV 与会话数据。当前开发候选的同格式数据和已安装新版插件保留；实验聊天停用不会删除其历史。

插件是可信本机代码，请只安装可信来源。模型目录的报价来自 models.dev，仅用于信息查阅，实际计费以供应商为准。
