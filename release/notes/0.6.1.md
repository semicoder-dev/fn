# fn 0.6.1

普通插件安装、更新、启用、停用和卸载现在会在任务空闲后局部生效，保留未变化页面、插件草稿和输入焦点，不再每次刷新整个窗口。运行时继续使用 Bun。

共享内核或基础组合变化、嵌套插件组合、无法安全释放的插件仍受控重启；热更新失败会恢复上一有效组合并重启干净进程。被更新插件自身的临时组件状态可能重建，请保存重要内容。浏览器在普通热更新时保持连接，后台重启后需从应用重新打开。

从 0.6.0 升级保留现有插件、连接和业务数据。运行时产物发生变化，请退出应用后使用完整 DMG 替换；无需迁移或重建现有官方插件。0.5.x 及更早版本仍使用独立旧数据目录，不读取、迁移或删除，需重新配置连接和安装插件。

本次继续内嵌与公开归档一致的 SDK 0.5.0，不发布新版 SDK 或官方插件；新增热更新声明的 SDK 构建支持暂缓。

Chat、手机与 CloudKit 聊天不在本次发行范围。
