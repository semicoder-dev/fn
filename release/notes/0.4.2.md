## 插件市场

- 应用不再内置或携带插件，首次启动进入应用中心。翻译、随手记从官方市场自主安装。
- 应用中心提供「插件市场」和「已安装」，支持搜索、来源筛选、刷新和市场源管理。官方源也可停用或删除；成功索引保留离线缓存及更新时间。
- 进入市场检查更新，逐个点击安装或更新。继续支持 npm、Git 和本地 `.tgz` 手动安装。
- 市场归档校验 SHA-256、插件 ID、包名、版本与 SDK；更新绑定原市场，暂存验证后切换，失败恢复旧版本。更新保留启停状态、KV 和历史，运行中的调用阻止替换。

## 界面与开发

- 主题模式和配色统一到「设置 → 外观」。
- SDK 0.3.1 删除 `builtin`，插件信息增加市场来源，安装任务增加操作类型和目标版本。manifest 仍为 `0.3`，模型、KV、UI 接口不变；官方插件固定使用公开 SDK 0.3.0 构建。
- FIA API 新增 `marketplaces.list/add/update/remove/refresh/catalog`、`plugins.installFromMarket` 和 `plugins.update`；删除 `plugins.installExample`。SDK CLI 与 notes/model 开发模板继续提供。
- 官方插件独立维护于 https://github.com/potato47/malatang-plugins ，每个插件独立发布归档，验收后更新市场索引。

## 升级须知

本版本处于开发阶段，插件安装记录及接口直接调整，不提供旧记录迁移。**升级前请在旧版应用中卸载所有手动安装的插件，然后退出并使用完整 DMG 替换应用。** 内置翻译不需要卸载，升级后从市场重新安装。旧版手动插件记录若仍存在，新版可能无法读取 `platform.json` 并启动；请先使用旧版完成卸载。不要删除整个数据目录或 `platform.json`，其中包含模型配置、API Key、KV 和历史。

宿主不会主动清除模型、凭证、插件 KV 或历史。插件 ID 保持不变，重新安装相同 ID 可继续访问既有 KV。手动安装不会自动关联官方市场；如需使用市场更新，先卸载后从所选市场安装。首次官方版本为翻译 0.1.0、随手记 0.1.0。

应用 0.4.2 / build 6，SDK 独立发行 0.3.1。FIA 独立 npm 继续暂停。跨版本代码热更新不作为本次验收路径。
