# Fn 0.8.2

- 普通页面和 TypeScript 更新复用经过验证的 0.8.1 固定运行时，避免原生程序重复编译导致不必要的完整重装。
- 安装包与应用内更新由同一份代码构建生成；发布前验收真实旧版更新、重启、数据保留及失败回退，再发布相同产物。
- 更新文件、完整安装包和更新清单分阶段上线；校验失败或运行时输入变化会阻断普通代码发布。

## 更新与数据

已安装 **0.8.1** 可在应用内检查、下载并确认更新。后台会重启，界面会刷新；请先保存未完成的编辑。现有应用、模型连接、业务数据、摘要和偏好保留。

**0.8.0** 用户需要一次完整安装，可直接下载安装 0.8.2，无需先安装 0.8.1。每版仍提供完整 DMG 供新用户安装；提供 DMG 不意味着已有 0.8.1 用户需要重装。

SDK/UI npm、独立应用、市场及手机版本不变。本次不替换用户日常安装。安装入口：https://semicoder.dev/fn/docs/installation
