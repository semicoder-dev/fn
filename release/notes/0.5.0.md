# fn 0.5.0

fn 采用 Bun 宿主与原版 dsh / Cordis 内核，应用、模型连接、Agent 和 Session 由新的插件框架统一管理。

- 恢复紧凑应用侧栏、二级设置、主题外观、模型管理、应用中心和自动更新。
- 同一服务商支持多个独立连接；支持 API Key 与 Pi 订阅登录、账号模型目录和已添加模型。Session 固定连接，换账号新建会话。
- 插件采用普通 npm 包与 Cordis 生命周期，后端直接执行 TypeScript；前端共享 React 和 SDK UI，可使用 SVG 图标及切页保留草稿。
- Session 使用 SQLite 持久化，支持工具循环、流式展示、取消、审批和重启恢复；中断的副作用不会自动重放。
- Chat v3 通过同一 iCloud 账号连接桌面与手机，支持多个会话、离线命令、共享已读、自定义交互卡片与已添加模型筛选。手机需升级至 0.3.0（4）内测版。
- 插件安装或更新先验证完整运行目录，等待后台任务空闲后切换；窗口保留并自动重连。
- SDK 0.4.0、三个 Cordis 官方应用使用独立的新契约与市场。网页工具升级至 agent-webtool 0.8.2，修复验证码被误判为零结果。

## 升级

必须下载完整 DMG 替换桌面应用。本次不兼容旧 SDK、旧插件和 Chat v2 客户端；模型连接及应用需要重新配置。新架构使用独立数据目录，不读取、迁移或删除旧数据。运行目录与数据库分别管理，不能将新数据直接交给旧内核。

同进程插件属于可信本地扩展，拥有本机代码执行能力。默认工具策略需要批准写入、进程和外部副作用；应用可显式选择自动执行。
