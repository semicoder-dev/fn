# Fn 0.7.0

- 看板首页合并为单行工具栏，保留“我的看板”及数量、搜索、归档和新建操作；去掉页面内重复标题，窄窗口使用带名称提示的操作图标。
- 修复 Fn UI 组合类名未逐个解析导致的看板顶部布局、状态文字和标签样式失效；看板标签深色配色使用 Fn 主题标记。
- Fn UI 统一参考 dsh 原版明暗配色，集中 theme.css 语义变量；移除桌面的重复主题定义，宿主与独立应用同步中性底色、按钮、焦点、输入和浮层颜色，不增加 dsh 依赖。
- Fn 多应用桌面、独立原生窗口、每应用 Bun 后台和受管理进程组；打开、最小化、关闭与崩溃隔离。
- 桌面改为单行搜索/整理/添加应用工具栏，搜索框自动填满操作按钮左侧的剩余宽度，搜索弹窗输入框铺满内容区并随窗口收缩；应用中心、通知、设置常驻底部 Dock 并使用弹窗，普通运行应用由竖线分隔。模型入口归入设置。移除卡片区域下方的运行状态文字和标语。
- 桌面采用全宽紧凑布局，插件用单个 size 声明 1x1、2x1、2x2 等固定网格规格；基准列宽和行高 240px、间距 12px，不足一列的余宽均分给各列，高度不变，末行保留完整空格位。整理桌面支持排序和移除，尺寸随应用包定义；开发预览复用正式尺寸规则。
- TypeScript Manifest/SDK、HTTP/SSE/WebSocket、浏览器开发重建与运行代校验、自有 Fn UI、JSON 小组件、应用安装更新。
- 官方 ChatGPT 授权、模型目录、OpenResponses、取消与完成终态；业务 Agent loop 由应用实现。
- 翻译、笔记、看板与独立业务持久化。
- 中英、明暗/系统主题、展示名称 Fn、Bun 1.4.4 和 bun fmt；清理被替换的运行依赖和构建工具。
- FIA 开发网关的本机 HTTP/SSE/WebSocket 显式直连，修复配置 HTTP 代理时 `bun dev` 停在加载页的问题；外网请求代理保持原有配置。


- 应用市场支持经过逐跳校验的 HTTPS 下载跳转，并限制下载大小。
- 手机文字中转保留开发预览；正式桌面版本暂不提供手机入口或 CloudKit 连接。

需要完整 macOS Apple Silicon 安装包。SDK 0.6.0、Fn UI 0.1.0；翻译、笔记、看板 0.2.0 通过应用中心安装。
