# fn 0.5.2

## 改进

- 插件安装、更新和卸载共享固定内核，仅准备变化的插件及其私有依赖，不再复制整套运行目录。
- 安装进度区分市场检查、下载、解包、应用版本准备、依赖校验和启动检查。
- 保留共享依赖单例校验、启动预检、任务空闲后切换和失败回退。历史运行目录暂不自动清理。

本机使用同一正式内核与三个官方插件归档测试，安装准备中位数由 5.808 秒降至 0.189 秒，减少约 96.7%。该测量不含网络下载、首次内核解包、等待任务空闲、后台重启和页面重连，不代表所有设备的完整安装耗时。

## 升级

本次需要退出 fn 后使用完整 DMG 替换应用。0.5.x 的连接、会话、KV 和已安装应用保留，无需重新配置；旧运行目录在新目录验证成功后才切换。0.4.x 或更早版本仍使用独立数据目录，不读取、迁移或删除旧数据。

SDK 0.4.0、三个官方 Cordis 插件 0.1.0、手机内测 0.3.0（4）及 agent-webtool 0.8.2 不变。本次不扩大真实 OAuth 刷新、多账号和手机跨设备场景的验收范围。
