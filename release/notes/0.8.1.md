# Fn 0.8.1

- 应用中心标题栏固定，本地安装和检查更新移入标题栏右侧，应用列表独立滚动；收紧内容顶部留白，窄窗口自动换行。
- 应用来源输入行铺满可用宽度，地址框获得更多空间；窄窗口输入框分行铺满，添加按钮右对齐。
- 更新、卸载、忙时关闭和未保存确认补齐正文与按钮间距，操作按钮统一右对齐。
- 打开弹窗时默认聚焦标题，关闭按钮不再自动显示蓝色焦点框；保留 Tab 焦点提示和 Escape 返回。
- 首页应用行使用单层焦点边框，内置新建应用模板使用公开 SDK 0.7.1 / UI 0.2.1。

## 安装与数据

使用完整 DMG 更新 Fn。现有 0.8 应用、模型连接、业务数据、缓存和偏好保留，无需重装独立应用。

SDK/UI npm 仍为 0.7.1 / 0.2.1；看板仍为 0.3.1，翻译、笔记和模型目录仍为 0.3.0。本次不重新发布这些包或市场。宿主内置 Modal 布局和初始焦点修复不改变已有独立应用的打包页面；独立应用需后续使用新 UI 重建发布才能同步。手机正式版不在本次范围。

安装入口：https://semicoder.dev/fn/docs/installation
