# fn 0.4.4

原麻辣烫正式更名为 **fn**。本次以独立应用身份发行，面向 macOS 14+ / Apple Silicon。

## 名称与安装

- 应用为 `fn.app`，标识为 `com.semicoder.fn`；命令行为 `fn`。开发与预览实例分别为 `fn Dev` / `fn-dev`、`fn Preview` / `fn-preview`。
- 使用本次完整 DMG 安装。fn 使用新的独立数据目录，需要重新配置模型、登录 ChatGPT 并安装插件；不读取、迁移或删除旧应用数据。
- 官网为 [semicoder.dev/fn](https://semicoder.dev/fn)，统一入口为[安装指南](https://semicoder.dev/fn/docs/installation)。更新源切换为 fn 独立签名更新站，历史发行保持原样。

## 插件与开发

- SDK 包名为 `@semicoder/fn-sdk`，本次内嵌 0.3.4。插件清单字段改为 `fn`，样式例外字段为 `fnStyleExceptions`，运行时全局标识使用 `__FN_BRIDGE__` / `__FN_MODULES__`。
- 只接受新契约，不提供旧包名、旧插件或旧 CLI 别名。原插件需更新并重新构建；manifest 兼容版本仍为 `0.3`。
- 应用不内置插件。从应用中心的官方市场自主安装译文和随手记 0.1.2；业务 ID `translate` / `quick-notes` 保持不变。
- `fn plugin create` 携带固定 SDK 快照，生成的 notes / model 项目可独立安装依赖、检查、构建和打包。

## 发行边界

Build 8，FIA 0.18.0 与 Bun 1.4.3。FIA 独立 npm 继续暂停；本次未添加通用框架接口或新的模型服务。ChatGPT 凭证仍存放在权限受限的本地明文文件。
