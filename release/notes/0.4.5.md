# fn 0.4.5

## 新增与改进

- 插件前端和后端可直接使用 `web.search` / `web.fetch` 搜索网页、读取正文，支持 `AbortSignal` 取消。
- 搜索结果包含来源编号及各引擎状态；抓取结果包含最终地址、HTTP 状态、标题和截断信息。每次调用独立编号，不保存网络历史。
- 宿主管理网络任务的并发、时限和结果大小，并在插件变更、应用更新及退出时检查和清理任务。前端断线后可恢复查询。
- 网络能力复用 agent-webtool 0.8.1，响应采用流式大小限制，取消与超时覆盖 DNS 等待及正文读取。

## 兼容与升级

本次附带 SDK 0.3.5，manifest 仍为 0.3。已有 fn 插件继续可用，不需要强制重建；使用新网络接口的插件需要 fn 0.4.5 及配套 SDK。官方译文和随手记保持 0.1.2。

本次运行时标识与 0.4.4 不同，需从[安装指南](https://semicoder.dev/fn/docs/installation)下载并替换完整 DMG，不能仅安装代码更新。现有 fn 数据保留。旧名称应用的数据及插件不迁移。

本次不包含模型自动工具调用、agent loop、动态浏览器或登录态网页支持。
