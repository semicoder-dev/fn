# Fn 0.8.5

- “显示桌面”移到状态栏菜单第一项，并用分割线与常用应用分开；保留应用列表、系统操作和退出的分组。
- 桌面工具栏与应用列表最大宽度统一为 1200px、水平居中，大屏不再过度拉伸；窄窗继续自适应。
- 修复开发工具本机就绪探测受 HTTP 代理影响的问题，保留失败状态和超时检查。
- 本次状态栏菜单变更位于 Swift/AppKit 原生宿主，0.8.4 及更早版本需下载完整安装包替换一次；已有应用、配置、摘要和业务数据保留。这不是无原生变化的重复编译漂移。

本版 build 21。SDK 0.8.0、Fn UI 0.2.2、翻译 0.3.1 及其他独立应用无需因本次宿主更新重装或改版；手机、FIA 独立 npm 和应用市场不改版。完整 DMG 与更新清单来自同一签名候选，经过真实旧版安装与数据保留验收后提升发布。
